# HR Analytics — Data Analysis Portfolio Project

## Overview

This project demonstrates an end-to-end HR analytics workflow using **SQL, Excel, Power BI, and Tableau**.

The goal is to explore workforce data, identify useful HR metrics, and present findings through interactive dashboards and analytical queries.

> **Portfolio note:** This repository is a personal analytics project. The included dataset and project materials are used for demonstration and portfolio purposes.

## Business Questions

The analysis focuses on questions such as:

- How is the workforce distributed across departments and roles?
- What patterns can be observed in employee demographics and job characteristics?
- Which HR metrics are useful for monitoring workforce trends?
- How can SQL, spreadsheets, and BI dashboards communicate the same underlying data effectively?

## Tools & Skills

| Tool | Skills demonstrated |
|---|---|
| **SQL** | Data querying, filtering, aggregation, joins and analytical queries |
| **Excel** | Data preparation, formulas, pivot tables and dashboard analysis |
| **Power BI** | Data modeling, measures, KPI cards and interactive dashboards |
| **Tableau** | Data visualization and dashboard design |
